Starbucks Sales Data Analysis

Microsoft Excel • Data Analysis

Sample data: this project uses simulated coffee-shop sales (Aug–Oct 2025) created for practice. It is not real Starbucks data.

I built a daily sales table in Excel and used formulas (SUMIFS, COUNTIFS, AVERAGEIFS, INDEX/MATCH) to summarize revenue and units by product, day of week, and month, then estimated daily sales for products such as the Cappuccino and the Pumpkin Spice Latte.
